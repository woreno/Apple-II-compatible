# Apple-II-compatible (2021)
Ths is an Apple II compatible built from scratch. As it was made by transfer photo-paper and etching with ferric chloride, and made the traces wider to avoid errors; as result the board didn't fit the A4 copper sheet and memory and slots were made in 2 different boards. 
* The DRAM logic is a bit different from the original.
* System ROM halves are selectable by a switch; one half will run a memory test, another half is Apple II original ROM.
* Character ROM layout is different as pins differs.
* The keyboard and keyboard board were also etched, and theres a ROM that translates the scancodes into ascii - the original had a GY AY-5-3600 chip with a integrated ROM etched from factory.   
* It just has 4 slots instead of 8. Never tested a the slots as i have no Apple II cards. 
Despite this i had planned to assign a number to each of them using a small ROM to store them, and having 7-segment displays to display their number but this as too cumbersome and i stopped the project.
